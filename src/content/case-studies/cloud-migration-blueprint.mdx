## Context & Bottleneck
Early-stage infrastructure grown through manual console changes eventually reaches an inflection point: deployments become fragile, staging diverges from production, and enterprise prospects begin asking hard questions about disaster recovery and uptime SLAs.

## Target Architecture Decisions
1. **Isolated Multi-Account Landing Zone:** Separated production, staging, and shared security/logging accounts to enforce strict blast-radius isolation.
2. **100% Reproducible IaC:** Codified VPC networking, NAT gateways, IAM roles, and managed Kubernetes node groups into versioned Terraform modules.
3. **Zero-Downtime Cutover Pattern:** Used logical database replication and weighted DNS routing to shift production traffic incrementally with instant rollback capability.

## Key Deliverables & Handover
- Complete Terraform module repository with CI plan/apply workflows.
- Architecture Decision Records (ADRs) documenting compute sizing and networking trade-offs.
- Incident response and disaster-recovery failover runbooks tested with the engineering team.
