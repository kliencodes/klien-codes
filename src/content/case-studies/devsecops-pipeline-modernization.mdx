## Context & Bottleneck
Enterprise buyers increasingly require verifiable supply-chain security and least-privilege access controls before signing annual contracts. Long-lived IAM keys in CI pipelines represent one of the highest-impact cloud risks.

## Target Architecture Decisions
1. **Keyless OIDC Federation:** Eliminated static cloud keys by federating GitHub Actions directly with cloud IAM using branch-scoped trust policies.
2. **Automated Security Gates:** Integrated SAST, dependency auditing, SBOM generation, and container image scanning directly into pull-request workflows.
3. **Audit-Ready Evidence Trail:** Enforced signed releases, peer-reviewed infrastructure changes, and centralized immutable logging for SOC 2 / ISO 27001 readiness.

## Key Deliverables & Handover
- Hardened reusable CI/CD workflow templates.
- IAM least-privilege policy baseline and secrets rotation runbook.
- Mapped technical controls checklist for external auditors.
