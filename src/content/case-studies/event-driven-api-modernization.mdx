## Context & Bottleneck
Full rewrites rarely succeed on schedule. Instead of halting feature delivery for a year, the goal was to relieve database lock contention and isolate bursty background workloads incrementally.

## Target Architecture Decisions
1. **Strangler-Fig Extraction:** Carved out webhook ingestion and report generation behind clean API contracts while keeping core domain logic stable.
2. **Durable Async Queues & Idempotency:** Replaced fragile in-request retries with idempotent background consumers and dead-letter alerting.
3. **End-to-End Trace Visibility:** Added OpenTelemetry tracing across API gateway, workers, and PostgreSQL queries to pinpoint latency regressions immediately.

## Key Deliverables & Handover
- Phased modernization RFC and API contract specifications.
- Production worker service template with graceful shutdown and retry policies.
- Latency/SLO dashboards and database indexing playbook.
